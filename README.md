# BDI-Based Explainable AI for Architectural Design

Bachelor's project by **Rakan Al-Swayyed** · **Universität Hildesheim** · **2020**

This research project explores how a belief–desire–intention (BDI) agent architecture can make case-based architectural design recommendations easier to understand. It extends the MetisCBR research framework with agents that organize and generate explanations for floor-plan retrieval results.

## Research focus

- Connect query context and retrieved design results to explanations.
- Organize explanation behavior through belief, desire and intention agents.
- Support relevance, justification and transparency explanation patterns.
- Combine knowledge-based reasoning with a multi-agent software architecture.

## Technical approach

The project uses Java, JADE agents, myCBR, graph matching, Maven and IntelliJ IDEA. Its explanation workflow interprets the available result context, selects explanation patterns, and executes plans that produce user-facing explanation text.

The work builds on the existing MetisCBR framework and related research software; it does not claim sole authorship of that underlying platform.
